# Mây mới Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the weekly AI call into one deep story per call that Mây remembers, personalizes from a growing family memory, keeps private until the teller agrees to share, and turns into gentle nudges that get family members to call each other.

**Architecture:** Two new server modules carry the new data: `server/memory.ts` (the memory book, one Gemini extraction per finished call, backfill, "what Mây remembers" API) and `server/may.ts` (signal queue, nudge sending with quiet hours and caps, contact tracking, story notifications, the nudge switch). `server/place.ts` answers "what time and weather is it where this person is", `server/callfacts.ts` assembles the larger script input (memory facts, occasions in 30 days, topic map). The call script becomes version 2 (`v: 2`): check-in, one main story with up to 4 follow-ups, photo, share consent, relay; the client flow and a new share-consent state machine (`src/callShare.ts`, same pattern as `src/callPhoto.ts`) follow it. Episodes get a `shared` flag; every listing filters other people's private episodes.

**Tech Stack:** React 19 + Vite (`app/src`), Express 5 + Postgres via `pg` (`app/server`), run with `tsx`, tests with `node:test`, Gemini text through `server/ai.ts` (`askJSON`), Web Push through `server/push.ts`.

**Spec:** `docs/superpowers/specs/2026-11-20-may-moi-design.md` (approved 20/11/2026). Sections "Chốt thêm sau khi soát" and "Người dùng trả lời (20/11)" override earlier sections. Read the whole spec before your task.

All paths below are relative to `app/`, where every command runs. `../HANDOFF.md` and `../docs/...` are at the repo root.

## Global Constraints

- Branch `ux-simple-poetic`, main checkout. Do not deploy, push, run `railway`, or connect to any database (local or live).
- Tests never need Postgres or the network: fake DBs in the style of `server/members.test.ts`, `server/chat.test.ts`, `server/shot.test.ts`; Gemini replaced by a stubbed `globalThis.fetch` as in `server/call.test.ts`. Modules that touch the DB take a `deps`/`db` parameter defaulting to `pool`, and export their SQL strings (like `SQL` in `server/chat.ts`) so fakes can match them exactly.
- Migrations run again on every boot and real users exist: only `create table if not exists`, `create [unique] index if not exists`, `alter table ... add column if not exists` (one `add column` per line, `server/members.test.ts` parses them). Never update or delete existing rows in a migration. Old calls and old episodes count as shared (`shared boolean not null default true`).
- Every new table or column that points at `members`, `families` or `calls` is covered by `PLAN` / `FAMILY_PLAN` in `server/members.ts` (`server/members.test.ts` fails otherwise). Do not name a column with the suffix `_by` or containing `member` unless it really points at a member (the detector in `members.test.ts` matches those names).
- Every user-facing string is an i18n key with vi, en and ko values, in `src/i18n/*.json` (client, and the `call.line.*` lines the server also reads) or `server/i18n/*.json` (server only), never in both. Vietnamese: short, warm, like a real person talking, no em dash (—) or en dash (–), no UI narration. Korean follows the existing `ko.json` voice (해요체, honorifics toward parents, the mascot name only through `{mascot}`). Vietnamese copy given in this plan is final; translate it for en and ko.
- iPhone: animate only `transform` and `opacity`; reuse the existing `.fade` class, add no new animated properties.
- AI prompts are written in English and end with `Reply in <language>.` (use `LANG_NAME` from `server/call.ts`). Every line the AI writes passes `suspect()` from `server/guard.ts`. Every extracted fact and signal carries an evidence sentence that is found in that call's answers, otherwise it is dropped.
- Privacy: the survey answer `intro.unsaid` and the hard-to-say message answers (topic `loi-nhan`) never reach memory extraction, never become facts, never become questions for anyone. A fact with `visibility = 'self'` is only used when talking to the person who told it.
- Voice: Gemini only, about 70 new lines per day for the whole app (`GEMINI_TTS_DAILY`, `server/ttsgate.ts`). Fixed lines are spoken from the cache with `kind: 'fixed'` and warmed by `warmFixedVoices`; never bump `CACHE_VER`. When the budget is gone the client shows the text with the soft chime (existing behavior in `Call.tsx` `say()`).

## Review Focus

1. A weekly call started before this change (a `status = 'ready'` script of this week without `v: 2`) must be recomposed by `/call/start`, never replayed in the old three-question shape. Pinned in Task 3 (`scriptReusable` test).
2. Speech-to-text output that differs from the AI's quoted evidence only by case, punctuation, spacing or Unicode form (NFC/NFD) keeps the fact; a paraphrase drops it. Pinned in Task 2 (`foldText` / `findEvidence` tests).
3. A target word that only partly matches a member ("Anh" vs member "An"), two members with the same given name, or singular "con" in a family with two children sends no nudge to anyone. Pinned in Task 2 (`resolveTargets` test).
4. The same call extracted twice (an answer arriving after `/finish`, backfill overlapping `afterCall`) leaves the facts once and the signals once. Pinned in Task 2 (`extractCall` twice test).
5. A recipient with no usable time zone (no city, old city code, JSON city without `tz`, junk tz string) falls back to `Asia/Ho_Chi_Minh`, never throws, and never gets a nudge outside 9:00 to 21:30. Pinned in Task 2 (`tzOfMember` test) and Task 7 (`inWindow` test).

```ts
export type ShareStage = 'ask' | 'listen' | 'think' | 'wait' | 'done';
export type ShareEnd = 'yes' | 'no' | 'timeout' | 'hangup';
export type ShareState = { stage: ShareStage; end: ShareEnd | null };
export type ShareEvent = { type: 'asked' } | { type: 'heard'; text: string | null } | { type: 'yes' } | { type: 'no' } | { type: 'timeout' } | { type: 'hangup' };
export const SHARE_START: ShareState;           // { stage: 'ask', end: null }
export const SHARE_HEAR_MS = 8000;
export const SHARE_WAIT: Partial<Record<ShareStage, number>>; // { listen: SHARE_HEAR_MS + 4000, think: 7000, wait: 12000 }
export function shareAnswer(text: string | null | undefined, lang?: 'vi' | 'en' | 'ko'): 'yes' | 'no' | null;
export function shareNext(s: ShareState, e: ShareEvent, lang?: 'vi' | 'en' | 'ko'): ShareState; // unchanged event returns the same object
export const shareMic: (s: ShareState) => boolean; // on in ask, listen, done
```

## Decisions this plan makes where the spec left room

- `replaced_by` is named `replacement_id` (the member-reference detector in `members.test.ts` flags any column ending in `_by`).
- The episode owner is the existing `podcasts.member_id` (always the teller for story episodes); only `podcasts.shared` is added. Consent lives on `calls.shared`, copied to episodes at render.
- `worry` signals are extracted but never queued: the approved expiry and priority lists name no `worry`, and "Chốt thêm" 6 forbids nudges about other people's health or sadness. They stay in the memory book as `self`.
- `low`, `good_news` and `upcoming` must be about the teller; they go to every other member (one nudge per recipient per day keeps it quiet). `miss` and `want_contact` go to the resolved target only.
- Tapping a nudge opens a voice call (not video) with the teller.
- Story notifications use the same queue (quiet hours, 72 h expiry) but do not count toward the nudge caps, ignore the nudge switch, follow the "Tin nhà" push switch, and create no `may_nudges` row.
- The check-in becomes a new topic `hoi-tham`, which never becomes an episode; the goodbye becomes a fixed, cached line (saves a voice line per call and no longer promises the family will hear a story the teller may keep private).
- The share question is skipped when the teller is alone in the family (the story stays private, the share button is there later).
- Two-generation episodes and a separate "kể liền mạch" video style are not built now; story episodes already join the teller's turns without Mây's voice.
